# OpenSimu

[简体中文](README.md) · [English](README.en.md) · **日本語**

OpenSimu は、ネットワーク技術の研究者に向けたオープンソースの軽量ネットワークシミュレーションプロジェクトです。手元の PC で小規模なネットワークを構成し、機器の設定を変えながらパケットの転送経路を観察し、その実験をほかの研究者が再現できるようにすることを目指しています。

現在は設計段階です。まずは Huawei と Cisco のルーターを対象に、公開されている製品マニュアルに基づいて、機種とネットワーク OS のバージョンごとにインターフェース、設定コマンド、ルーティングの動作をモデル化する予定です。各機能には、参照したマニュアルの節と、動作を確かめるための実験例を添えていきます。

## 2 台のルーターで静的経路を検証する

R1 から経路を一つ削除すると、両端の PC は引き続き互いに `ping` できるでしょうか。最初のバージョンでは、この実験の再現を目指します。

```text
PC-A ─── R1 (Huawei) ─── R2 (Cisco) ─── PC-B
```

1. 3 本のリンクにそれぞれ異なる IPv4 サブネットを割り当てます。各 PC のデフォルトゲートウェイには、直接接続されたルーターを指定します。
2. R1 と R2 に、対向ルーターをネクストホップとする相手側 LAN への静的経路を設定します。この状態では、どちらの PC からも相手への `ping` が成功するはずです。
3. R1 から PC-B 側の LAN への静的経路を削除します。R1 のルーティングテーブルからその経路が消えることを確認します。R1 にデフォルト経路や代替経路がなければ、どちらの PC からの `ping` も失敗するはずです。PC-B からの要求が PC-A に届いても、応答を R1 から PC-B に転送できないためです。

続いて、VLAN によるネットワークの分離と、OSPF による動的な経路学習を扱う実験を追加する予定です。
