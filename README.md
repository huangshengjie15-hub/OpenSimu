# OpenSimu

**简体中文** · [English](README.en.md) · [日本語](README.ja.md)

OpenSimu 是一个面向网络技术研究人员的开源轻量级网络仿真项目。我们的目标是让研究者在普通电脑上搭建小型拓扑，修改设备配置，观察数据包如何转发，并把同一个实验交给别人复现。

项目目前处于规划阶段。首期从华为和 Cisco 路由器入手，依据公开的产品手册，按设备型号和网络操作系统版本逐步实现接口、配置命令和路由行为。每项实现都计划附上对应的手册章节和可复现的实验。

## 用两台路由器验证静态路由

在下面的拓扑中，如果只删除 R1 上的一条路由，两端的主机还能互相 `ping` 通吗？这是首个版本要能复现的场景。

```text
PC-A ─── R1 (Huawei) ─── R2 (Cisco) ─── PC-B
```

1. 给三段链路分别分配一个 IPv4 子网，两台主机各自使用相邻路由器作为默认网关。
2. 在 R1 和 R2 上分别添加一条静态路由，下一跳指向对端路由器，目的网段为对端 LAN。此时从任一主机发起的 `ping` 都应成功。
3. 删除 R1 上通往 PC-B 所在网段的静态路由。预期在 R1 的路由表中看不到该条目。如果 R1 没有默认路由或其他可用路径，两个方向的 `ping` 都应失败。即使 PC-B 的请求到达 PC-A，应答也无法经 R1 返回。

后续计划在此基础上增加 VLAN 隔离实验，以及使用 OSPF 自动学习路由的实验。

## 参与开发

欢迎在 Issue 中提出你想复现的设备行为。写明**设备型号和系统版本**，附上**公开手册的链接与章节**，再给出能说明问题的**最小拓扑、配置和预期结果**。如果已有实测结果，也欢迎附上有权公开的路由表或命令输出。[提交实验建议](https://github.com/huangshengjie15-hub/OpenSimu/issues)
